# Usability severity rubric (Garra / user config)

No automatic **blocker** for merge governance — use `major` as the highest practical severity unless the user later enables blockers.

| Severity | When to use |
|----------|-------------|
| **major** | Broken flow, misleading copy, serious a11y gap (unlabeled primary control), mobile layout breaks primary task |
| **minor** | Confusing UX, missing empty state, weak error copy, small a11y gap (secondary control) |
| **nit** | Copy polish, spacing, optional a11y enhancement |

Deprecated for this project: `blocker` — map former blockers to `major` and note in body if merge discussion is advised.
